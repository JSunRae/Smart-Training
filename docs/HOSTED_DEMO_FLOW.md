# Hosted Demo Flow

Last updated: 2026-05-16

Use this as the **default hosted pilot demo**. It is intentionally narrow, repeatable, and built on the seeded Challenger scenarios.

## Audience

Best for:

1. VP of Sales
2. Sales Enablement
3. RevOps
4. CRO

## Recommended sequence

1. Start on the dashboard and explain that the pilot is running the text-first workflow with transcript review.
2. Open `Frontline Coaching Consistency`.
3. Read the buyer opener out loud.
4. Give a weak first seller answer on purpose:

`We help managers coach more often with AI roleplay and transcript review.`

5. Trigger `Pause for coach`.
6. Use the coach correction to reframe the story:

`Most managers are coaching after calls go wrong. We give them a controlled place to correct objection handling before that risk shows up in pipeline.`

7. End the session and return to the dashboard to show transcript persistence.
8. Open `Forecast Confidence Through Coaching` and explain how the same platform supports a RevOps conversation about upstream pipeline quality.

## What the demo should prove

1. Smart Training is not a passive content library.
2. The product supports a repeatable before/after coaching moment.
3. Transcript review persists the practice session for manager follow-up.
4. The same platform can support VP Sales and RevOps buying narratives.

## Demo guardrails

1. Do not use `/voice-lab` in the hosted pilot demo.
2. Do not position the product as generic AI roleplay.
3. Always tie the pitch back to manager consistency, behavior variance, and risk entering live pipeline.
